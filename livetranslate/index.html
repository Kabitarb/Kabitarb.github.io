How updates work

  1. Add the source once (Feather: top button; ESign / Scarlet: paste the source link in Sources).
  2. Install Live Translate from the source so your signer can track it.
  3. When a new version is posted, the app shows Update available and your signer shows an Update button. Your settings are kept.
